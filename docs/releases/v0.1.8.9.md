# LiveDrop v0.1.8.9

Share files and web links between Windows, Windows Phone and compatible Quick Share devices on your local network.

- **Cancel incoming transfers:** Select Files becomes Cancel while receiving. Cancel stops the active transfer and removes unfinished files, then restores the normal controls.
- **Open received web links:** Explicit web-link shares open in the browser after a successful transfer instead of creating a text file. Ordinary text files continue transferring normally.
- **Open received files:** Completion notifications say **Press to view files** and open the saved file or batch folder when pressed. Link notifications can reopen the received link.
- Includes the English localization resource foundation introduced in 0.1.8.8, with existing notification fallback for older Windows versions.

Download the signed ARM/x86/x64 appxbundle. The existing signing certificate and update identity are retained; RetiredLake.cer and SHA256SUMS are included.

Validated with isolated loopback transfers covering multiple files, explicit URL attachments, URL-looking text files, cancellation from either side, and partial-file cleanup. Production loopback transfers remain disabled.
