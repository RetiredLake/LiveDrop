# LiveDrop v0.1.8.4 development preview

- Transfer notifications show native progress on supported Windows builds, then change to Share complete. Older builds retain text notifications.
- Tap a received-file completion notification to open the file. For multiple files, it opens the receiving folder.
- LiveDrop device names wait for their broadcast metadata and refresh correctly in the device list.
- The main screen header now reads LiveDrop 2; the installed app remains LiveDrop.
- Includes browser link sharing and the recent LAN discovery and ghost-device fixes.

For Windows 10 and Windows 10 Mobile 10.0.10586.0 or newer. Native notification progress requires 10.0.15063.0 or newer. File opening uses the apps available on the receiving device.

Download the ARM/x86/x64 appxbundle. The signing certificate is unchanged; install RetiredLake.cer only if it is not already trusted. SHA256SUMS contains hashes for both downloads.

This is a development prerelease ahead of 0.2.0.0 and is not served through the current stable Check for Update channel. The full development source is included in this tag. The 0.1.9.0 localization plan is in docs/localization-0.1.9.0.md.
