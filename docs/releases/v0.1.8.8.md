# LiveDrop v0.1.8.8 development preview

- Renames the file selection button to **Select Files**.
- Moves English interface text, dialogs, notifications, discovery messages and app-authored errors into Windows resource files, preparing LiveDrop for translations.
- Uses Windows language selection with English fallback. This preview remains English-only; translated languages will follow separately.
- Preserves existing file/link transfer behavior and the older Windows notification fallback.

Download the signed ARM/x86/x64 appxbundle. RetiredLake.cer and SHA256SUMS are included. This development prerelease remains outside the stable Check for Update channel ahead of 0.2.0.0.
