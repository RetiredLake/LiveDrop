# LiveDrop v0.1.8.6 development preview

- Progress notifications now show Sending to DEVICE or Receiving from DEVICE above the filename and progress bar.
- Keeps the Sending/Receiving status and percentage below the bar, without Windows' generic New notification placeholder.
- Older Windows builds retain their existing text notifications.

Includes the active-transfer cancellation fix from 0.1.8.5. The app name, signing certificate and minimum Windows version are unchanged.

Download the signed ARM/x86/x64 appxbundle. SHA256SUMS lists the bundle and certificate hashes. This is a development prerelease ahead of 0.2.0.0, outside the stable Check for Update channel.
