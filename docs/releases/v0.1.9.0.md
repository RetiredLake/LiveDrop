# LiveDrop v0.1.9.0

LiveDrop now follows your Windows language preferences with translations for the main interface, sharing prompts, common messages, and notifications.

Added languages: Arabic, Brazilian Portuguese, Czech, French, German, Hindi, Hungarian, Indonesian, Italian, Japanese, Polish, Russian, Simplified Chinese, Spanish, Ukrainian, Urdu, and Vietnamese.

Detailed technical diagnostics continue to use English fallback. Translations have not yet received native-speaker review.

Includes the sharing and consent improvements from v0.1.8.12. The signed universal package supports ARM, x86, and x64, with the same package identity and certificate for updates.

This concludes the current UWP development milestone. Future Windows 8.1 / Windows Phone 8.1 work will be planned separately.
