# LiveDrop v0.1.8.7 development preview

This preview carries forward the validated 0.1.8.6 transfer behavior ahead of the 0.2.0.0 release.

- Send files and web links over Google Quick Share LAN sharing.
- Phone-to-phone sharing uses the corrected local network discovery and addressing.
- Transfer cancellation, multiple large files, and notification activation have been confirmed through device testing.
- Progress notifications show Sending to DEVICE or Receiving from DEVICE, the filename, progress bar and percentage. Older Windows builds keep their existing text notifications.
- Open received files from completion notifications.

This is a version-only maintenance release; no protocol changes are introduced.

Download the signed ARM/x86/x64 appxbundle. RetiredLake.cer and SHA256SUMS are included. This development prerelease remains outside the stable Check for Update channel.
