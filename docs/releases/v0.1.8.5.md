# LiveDrop v0.1.8.5 development preview

- Cancel now stops an active outgoing transfer instead of only clearing the screen.
- Pending connections and socket operations stop on cancellation, and late progress updates cannot revive the canceled transfer display.
- Keeps the streamlined notification layout: filename, progress bar, then Sending/Receiving and percentage. Older builds keep their text notifications.

Includes the 0.1.8.4 notification, device-name, browser-link and discovery improvements. The visible header remains LiveDrop 2; the installed app and signing certificate remain LiveDrop.

The ARM/x86/x64 appxbundle is signed with the existing certificate. SHA256SUMS lists the bundle and certificate hashes. This is a development prerelease ahead of 0.2.0.0, outside the stable Check for Update channel.

Tested with isolated loopback cancellation during a blocked read and a partial file transfer, receiver cleanup, and normal multi-file/link transfers. Phone-to-phone hardware testing remains separate.
