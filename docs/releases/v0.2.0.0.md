# LiveDrop v0.2.0.0

- Sharper transparent app and tile icons, including high-resolution assets.
- Improved mobile file selection with the provider/location picker where supported, and an async fallback.
- Aligned the View Files action after receiving content.

Includes the translated interface and existing file/link sharing, multi-file transfers, incoming consent with PIN comparison, progress, cancellation, and received-file opening.

The signed universal bundle supports Windows 10 PCs and Windows 10 Mobile on ARM, x86, and x64. It keeps the existing package identity and signing certificate for updates.

Install the `.appxbundle`. The accompanying `RetiredLake.cer` is unchanged. Windows 8.1 / Windows Phone 8.1 development remains separate under `src/LiveDrop8`.
